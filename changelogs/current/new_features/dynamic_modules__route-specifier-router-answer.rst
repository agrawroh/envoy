Added ``router_answer`` to the virtual cluster override of the dynamic modules route specifier. It asks the module for the virtual cluster of each request at the router, with the headers the router forwards, instead of when route matching resolves. ``BUILT_ROUTES`` answers the routes the specifier builds, and ``EVERY_ROUTE_ENTRY`` answers every route entry it is handed without calling the module at route matching. A module opts in from its configuration constructor and exports the answer hook, which Envoy requires for a ``router_answer`` other than ``NONE``. A selection, or an answer, on a route whose virtual host already selects a virtual cluster is dropped and counted in ``virtual_cluster_stacked``. This also applies to a selection made with ``set_virtual_cluster`` under the default ``NONE``.
